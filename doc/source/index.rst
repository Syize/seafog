What is seafog?
***************

During my master's studies, I do some research about the marine fog. And I found tools we used to do research is quite old. We still use the shell script to download datas we need, use the C and Fortran program to calculate fog area from satellite data and WRF result. I think this should be changed. With all my respect and love to my tutor, I introduce the ``seafog`` package to all marine fog researchers.
